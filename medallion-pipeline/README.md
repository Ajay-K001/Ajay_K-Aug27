# Medallion Pipeline

A production-ready medallion architecture data pipeline with **human-in-the-loop STTM approval gates**, LLM-assisted transformations, and business-intent-driven analytics.

## Architecture

The pipeline implements the medallion lakehouse pattern with LLM agents:

```
Landing (Raw CSV)
       ↓ [Profiler Agent: LLM analyzes schema]
       ↓ [User approves Bronze STTM]
    Bronze Layer [Validation + Metadata]
       ↓ [Silver Agent: LLM guides cleaning]
       ↓ [User approves Silver STTM]
    Silver Layer [Deduplicated + Standardized]
       ↓ [Gold Agent: LLM computes KPIs]
       ↓ [User approves Gold STTM]
    Gold Layer [Business KPIs + Aggregations]
       ↓ [Reporter: Generates insights]
    Executive Report [JSON + HTML + PDF]
```

### Key Features

- **STTM Approval Gates**: Human-in-the-loop at each layer (Bronze/Silver/Gold)
- **LLM-Driven Agents**: Semantic Table Type Mapping generated by LLM schema analysis
- **Business Intent**: User can provide a business question to drive layer transformations
- **Multi-LLM Support**: Groq, OpenAI, Gemini, GitHub Models
- **Complete Data Flow**: Each layer reads from the previous layer (not landing CSVs)
- **Audit Trail**: LLM guidance and transformation notes stored in metadata

## Setup

### 1. Install Dependencies

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Configure LLM Provider

Copy `.env.example` to `.env` and set your API credentials:

```bash
cp .env.example .env
```

Then edit `.env` with one of these providers:

**Option A: Groq (recommended for free tier)**
```
LLM_PROVIDER=groq
GROQ_API_KEY=your_groq_key_here
GROQ_MODEL=llama-3.3-70b-versatile
```

**Option B: OpenAI**
```
LLM_PROVIDER=openai
OPENAI_API_KEY=your_openai_key_here
OPENAI_MODEL=gpt-4o-mini
```

**Option C: Google Gemini**
```
LLM_PROVIDER=gemini
GOOGLE_API_KEY=your_gemini_key_here
GEMINI_MODEL=gemini-2.5-flash
```

**Option D: GitHub Models**
```
LLM_PROVIDER=github
GITHUB_TOKEN=your_github_token_here
GITHUB_MODEL=openai/gpt-4.1-mini
```

## Usage

### CLI: Run with Approval Prompts

```bash
# Basic run (files default to data/landing/)
python app/main.py --run-id my-run-001 --business-intent "What is yearly sales by product?"

# Specify input files
python app/main.py --files data/landing/sales.csv data/landing/products.csv \
  --run-id my-run-002 --business-intent "Top 10 products by revenue"

# Skip approval gates (not recommended for production)
python app/main.py --skip-approval --files data/landing/sales.csv
```

At each layer (Bronze/Silver/Gold), you'll be prompted:
```
➤ Approve Bronze STTM? (y/n): 
```

Review the STTM JSON and type `y` to approve or `n` to cancel.

### Web UI: Streamlit App

```bash
streamlit run app/streamlit_app.py
```

Then open http://localhost:8501

**Workflow:**
1. Upload CSV files or use default landing data
2. Enter your business question (e.g., "What are the top regions by sales?")
3. Click **Run Full Workflow**
4. Review and approve **Bronze STTM**
   - See schema analysis and transformation rules
   - Click ✅ Approve or ❌ Revise
5. Review and approve **Silver STTM**
   - See cleaning and standardization rules
6. Review and approve **Gold STTM**
   - See KPI aggregation and dimensional rules
7. View generated report with insights, tables, and download PDF

## Data Flow Example

**Input:** `sales_data.csv` with columns: `transaction_id, transaction_date, store_id, product_id, quantity, unit_price, total_amount`

**Bronze Layer** (after LLM validation):
- Columns: all original + `_bronze_loaded_at`, `_bronze_source_file`, `_bronze_llm_validation`
- Format: Parquet
- Transformations: Schema inference, null tracking

**Silver Layer** (after LLM-guided cleaning):
- Deduplication applied
- Date columns parsed to datetime
- Lowercase standardization on strings
- Columns: all original + `_silver_cleaned_at`, `_silver_llm_guidance`, `_silver_business_intent`
- Format: Parquet

**Gold Layer** (after KPI aggregation):
- New KPI columns: `total_amount_total`, `total_amount_per_transaction`, `quantity_total`
- Dimensional aggregations: `total_amount_by_store_id`, etc.
- Columns: all above + `_gold_aggregated_at`, `_gold_llm_guidance`, `_gold_intent`
- Format: Parquet

**Report:**
- Executive summary with business insights
- Yearly sales by product table
- Yearly sales by location table
- JSON + HTML + PDF outputs

## STTM Approval Flow

**What is STTM?**
Semantic Table Type Mapping (STTM) defines how tables are transformed:
- Which columns are keys, metrics, dimensions
- What operations to apply (ingest, clean, aggregate)
- Data quality checks to enforce

**Why Approval?**
Before transforming data, humans review the LLM-generated rules to ensure they align with business requirements.

**How to Approve:**

1. **CLI**: Read the STTM JSON and type `y` or `n`
2. **Streamlit**: Click the "Approve" button to proceed, or "Revise" to stop and adjust

**Example Bronze STTM (Streamlit):**
```json
{
  "phase": "bronze",
  "description": "Raw data ingestion with schema inference",
  "source_to_target": {
    "source_files": ["data/landing/sales_data.csv", ...],
    "target_layer": "bronze_layer",
    "mapping": [{
      "source": "raw_csv",
      "target": "bronze_parquet",
      "operation": "ingest",
      "transformations": [...],
      "quality_checks": ["infer_schema", "detect_nulls", ...]
    }]
  }
}
```

## Business Intent

The **business intent** (your question) drives transformations:
- **Silver Layer**: Determines which columns to prioritize for cleaning
- **Gold Layer**: Guides KPI selection (if you ask about "products", product-level aggregations are prioritized)

Examples:
```bash
--business-intent "What are yearly sales by product and location?"
--business-intent "Which regions have the highest growth?"
--business-intent "Top 5 customers by lifetime value?"
```

## Outputs

All outputs are saved to `data/` and `reports/`:

- **Profiles:** `data/profiles/profile_combined_*.json` — Schema analysis
- **Bronze:** `data/bronze_layer/*.parquet` — Validated raw data
- **Silver:** `data/silver_layer/*.parquet` — Cleaned data
- **Gold:** `data/gold_layer/*.parquet` — Aggregated KPIs
- **STTM Rules:** `data/sttm/*.json` — Transformation rules
- **Reports:** `reports/report_insights.json|html|pdf` — Executive report

## Troubleshooting

**LLM calls timing out?**
- Groq is fast and free (recommended)
- Increase timeout or use a faster LLM model

**Pipeline fails at Silver/Gold?**
- Check that Bronze/Silver outputs exist in `data/bronze_layer/` and `data/silver_layer/`
- Ensure landing CSVs are present in `data/landing/`

**Approval stuck?**
- CLI: Press Ctrl+C to cancel and re-run
- Streamlit: Refresh the page and start over

## Architecture Decisions

- **Parquet over CSV** for intermediate layers for compression and speed
- **LangChain/LangGraph** for agentic patterns and tool use
- **Pydantic** for state management and validation
- **Streamlit** for zero-config web UI, matplotlib for PDF generation
- **Metadata columns** (`_bronze_*`, `_silver_*`, `_gold_*`) for audit trails without altering business data
